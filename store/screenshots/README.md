# Screenshots

Drop them here and run `node ../../scripts/check-shots.mjs` (or just ask).

The store wants 1280x800 or 640x400, PNG or JPEG, at most five. Anything else
gets rejected at upload, so they are checked and resized from here rather than
discovered at the console.

Order matters: the first one is what shows on the search result card, so it
should be the recording panel mid-flow with the reason lines legible.
